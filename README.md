## 🚀 Proyectos Destacados

### 🛰️ [dtn-core](https://github.com/srwangcr/dtn-core)
Motor DTN (Bundle Protocol v7, RFC 9171) de alto rendimiento orientado a entornos *bare-metal* y `no_std`. Implementa parsing CBOR en zero-copy, colas SPSC lock-free alineadas a caché, indexación con árboles de intervalos CGR y persistencia atómica mediante WAL con Direct I/O.  
`Rust` · `no_std` · `Systems Engineering` · `Networking`

### 🧬 [EvolucionIA — Economic Simulator](https://github.com/srwangcr/Ia_Economy_Sim)
Simulador de mercado de agentes heterogéneos con un motor dual en Python (Polars) y Rust (PyO3). Integra evolución genética mediante DEAP, calibración con Optuna, dashboard en Streamlit y persistencia optimizada en SQLite/PostgreSQL[cite: 1, 2].  
`Rust` · `Python` · `DEAP` · `Streamlit` · `PostgreSQL`

### 🔐 [Guardian Graph System](https://github.com/srwangcr/Guardian_Graph_System)
Sistema de defensa activa para entornos Linux. Genera honeypots, asigna niveles de riesgo por usuario y activa contención mediante Docker ante patrones de cifrado sospechosos en archivos señuelo[cite: 2, 6].  
`Python` · `Cybersecurity` · `Docker` · `GPLv3`

### 🌐 [Nexus Gateway](https://github.com/srwangcr/nexus-gateway)
API Gateway de alto rendimiento con rate limiting basado en Redis, validación de JWT con caché, reverse proxy con reintentos y despliegue clusterizado con PM2 en contenedores[cite: 2, 8].  
`TypeScript` · `Node.js` · `Redis` · `Docker`

### 📦 [Nexus Gestión](https://github.com/srwangcr/nexus-gestion)
Sistema full-stack minimalista (dark mode) para gestión de órdenes y proveedores, equipado con dashboard en tiempo real, autenticación JWT y diseño modular[cite: 2, 5].  
`React` · `Node.js` · `Express` · `PostgreSQL`

### 🤝 [Ayuda Tica MVP](https://github.com/srwangcr/mvp_7600)
Plataforma web enfocada en conectar donantes y reportar accesibilidad bajo la Ley 7600 en Costa Rica, con mapas interactivos y pasarela de pagos simulada[cite: 2].  
`React` · `Node.js` · `PostgreSQL` · `Cloudflare Tunnel`
