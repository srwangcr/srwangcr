## 🚀 Proyectos Destacados

### 🛰️ [dtn-core](https://github.com/srwangcr/dtn-core)
Motor DTN (Bundle Protocol v7, RFC 9171) de alto rendimiento orientado a entornos *bare-metal* y `no_std`. Implementa parsing CBOR en zero-copy, colas SPSC lock-free alineadas a caché, indexación con árboles de intervalos CGR y persistencia atómica mediante WAL con Direct I/O.  
`Rust` · `no_std` · `Systems Engineering` · `Networking`

### 🏛️ [GovSim](https://github.com/srwangcr/GovSim)
Simulador de escenarios de política pública. Arquitectura híbrida con motor de simulación pareada en Rust compilado a WebAssembly (Web Worker), API de validación concurrente en .NET 8, PWA en React 18 y persistencia de documentos JSONB en PostgreSQL 16 con caché en Redis 7.  
`Rust` · `Wasm` · `.NET 8` · `React` · `PostgreSQL`

### 🧬 [EvolucionIA — Economic Simulator](https://github.com/srwangcr/Ia_Economy_Sim)
Simulador de mercado de agentes heterogéneos con un motor dual en Python (Polars) y Rust (PyO3). Integra evolución genética mediante DEAP, calibración con Optuna, dashboard en Streamlit y persistencia optimizada en SQLite/PostgreSQL.  
`Rust` · `Python` · `DEAP` · `Streamlit` · `PostgreSQL`

### 🛡️ [Anti Leak Client](https://github.com/srwangcr/anti-leak-client)
Aplicación de escritorio multiplataforma (Tauri 2 + Rust) para verificación de origen de imágenes y OSINT. Implementa procesamiento local de hashes criptográficos (SHA-256) y perceptuales (pHash), con puente hacia Google Cloud Vision API para Web Detection.  
`Rust` · `Tauri 2` · `OSINT` · `TypeScript`

### 🔐 [Guardian Graph System](https://github.com/srwangcr/Guardian_Graph_System)
Sistema de defensa activa para entornos Linux. Genera honeypots, asigna niveles de riesgo por usuario y activa contención mediante Docker ante patrones de cifrado sospechosos en archivos señuelo.  
`Python` · `Cybersecurity` · `Docker` · `GPLv3`

### 👻 [Kelpie-Ghost](https://github.com/srwangcr/Kelpie-Ghost)
Herramienta de análisis de red y pentesting orientada a la evasión. Orquesta la creación de interfaces de red virtuales efímeras (veth) con identidades L2/L3 aleatorias (MAC/IP) en Linux para paralelización de escaneos y ofuscación de topología.  
`Python` · `Scapy` · `Linux Networking` · `Security`

### 🌐 [Nexus Gateway](https://github.com/srwangcr/nexus-gateway)
API Gateway de alto rendimiento con rate limiting basado en Redis, validación de JWT con caché, reverse proxy con reintentos y despliegue clusterizado con PM2 en contenedores.  
`TypeScript` · `Node.js` · `Redis` · `Docker`

### 📦 [Nexus Gestión](https://github.com/srwangcr/nexus-gestion)
Sistema full-stack minimalista (dark mode) para gestión de órdenes y proveedores, equipado con dashboard en tiempo real, autenticación JWT y diseño modular.  
`React` · `Node.js` · `Express` · `PostgreSQL`
